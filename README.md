[Fontselect jQuery Plugin](https://av01d.github.io/fontselect-jquery-plugin/index.html) fork used in MetaSlider

### Requirements

- node v19.2.0+

### Important!

Don't manually update the minified version, instead use terser for this process.

### Install laravel-mix

Install terser by running `npm install`

### Minify Javascript

With every change to jquery.fontselect.js, is required to update the minified version by running `npm run build`
